# Lab 4: From Counts to Dependence Structures

A 2-hour hands-on lab in which students build a graph of dependence/independence from a categorical dataset.

## Files

| file | purpose |
|---|---|
| `04_dependence_structures_counts_to_graphs.ipynb` | Student notebook |
| `lab_helpers.py` | Utility functions (load, tables, tests, plots) |
| `student_worksheet.md` | Printable worksheet for group work |
| `OPTIONAL_extensions.md` | Advanced material for fast groups or follow-up |
| `data/` | `group_A.csv` … `group_H.csv` and `collider_upgrade.csv` |

## What students do

1. Explore marginal distributions.
2. Test all 6 unordered pairs for association.
3. Use conditioning to decide which associations are direct.
4. Build a graph from the conditional-independence facts.
5. Investigate sample-size effects and a collider example.

## Running the lab

Open `04_dependence_structures_counts_to_graphs.ipynb` in JupyterLab or VS Code. Make sure `lab_helpers.py` and the `data/` folder are in the same directory as the notebook. Each student group should change `MY_GROUP` to their assigned letter.

## Dependencies

- Python 3.10+
- `numpy`, `pandas`, `matplotlib`, `scipy`

The traveller datasets were generated by the model in `slides and readers/stats/model.py` and pass the QA gate in `slides and readers/stats/qa.py`.
