# ML Studio – Understanding Models

**ML Studio** is a hands-on learning space for students who want to go beyond “getting code to run” and start truly understanding what machine learning models are doing.

The goal is simple:  
To develop strong modeling intuition.

Instead of focusing only on metrics or finished pipelines, we explore how models behave, why they behave that way, and how our choices shape outcomes.

---

## What You Can Expect

- Visual and intuitive explanations  
- Guided hands-on experimentation  
- Simple datasets to expose core ideas    

These sessions are designed for students who are curious, reflective, and motivated to deepen their technical reasoning by hands-on experimentation.

ML Studio helps you build the mental models needed to answer this type of questions confidently:

- Why did this model behave like that?
- What assumption is this algorithm making?
- Why is it overfitting?
- What changed when I tuned that hyperparameter?
- How does data representation affect outcomes?


---

## Initial Topics

### 1. Understanding Models Visually
Compare algorithms such as logistic regression, SVM, kNN, and decision trees on the same synthetic datasets.  
Visualize decision boundaries and see how different modeling assumptions produce different behaviors.

### 2. Models Are Controlled by Complexity
Explore hyperparameters and the bias–variance tradeoff through visual experiments.  
Understand overfitting, underfitting, and generalization using learning curves instead of isolated accuracy scores.

### 3. Models Can Encode Bias
Investigate how data influences model behavior.  
Explore feature importance, proxy variables, and simple bias diagnostics to understand how structural bias can appear in models.

### 4. Data Lives in Vector Space
Develop intuition for vectors, distance, and cosine similarity.  
Experiment with representation, scaling, and normalization to understand why linear algebra is fundamental to machine learning.
