# MDP design

Material for the "design your own MDP" workshop in Decision Theory (DETH).

| File | What it is |
|---|---|
| [mdp-design-workshop.md](mdp-design-workshop.md) | **The reader.** Goal, design principles, patterns, common mistakes (and flaws seen in earlier student designs), example ideas, the task and the sanity checks. Ideas only, no long code. |
| [mdp-environment-standard.md](mdp-environment-standard.md) | **All the code.** The environment standard (`reset`/`step`, Gymnasium style, no Gym needed), a template for a bigger environment, a random baseline, an environment checker, Q-learning, a comparison plot, and (later) value iteration. Optional to follow. |

Start with the reader. Copy code from the standard when you need it.
