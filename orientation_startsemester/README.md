# Orientation Start Semester

Welcome to the orientation phase of the Machine Learning course. This module is designed to introduce you to the core concepts of Artificial Intelligence and Machine Learning, blending high-level inspiration with foundational hands-on technical workshops.

The orientation is structured into two main parts:
* **Inspiration:** A high-level introduction to kickstart your creative thinking about AI capabilities.
* **Workshops:** Technical lab sessions where you transition from observing AI capabilities to understanding how models actually learn.

After completing this orientation phase, the course will transition into the **ML Studio** module, where we will dive deeper into model mechanics, complexity, fairness, and vector spaces.

## Directory Structure

* `/Inspiration` - Core presentation materials and the first interactive poster assignment.
* `/Workshops` - Weekly Jupyter notebooks covering applications, decision trees, and neural networks.
