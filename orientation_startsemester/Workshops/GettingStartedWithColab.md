# Getting Started

## Git and Google Colab

**Git** is a tool for storing and managing code and teaching materials. We use GitHub to share the course files and keep them organized.

**Google Colab** lets you run Python notebooks in your browser without installing Python or the required libraries on your computer.

For now, we will use Colab so you can get started quickly. Later, you can also set up a local environment using **Conda**, **VS Code**, and Git.

## Open the course materials in Colab

1. Go to [Google Colab](https://colab.research.google.com/).
2. Create a **New Notebook**.
3. On the left side, select the **GitHub** tab.
4. Enter:

   `https://github.com/imanmossavat/ml-teaching-materials-fontys/tree/main/orientation_startsemester`

5. Wait for the files to load.
6. Open the notebook you want to use.

This allows you to work directly with the course materials from GitHub without installing anything on your computer.

### Optional: Set up your own computer

For future sessions, you can try working locally by installing:

- **Conda** for managing your Python environment
- **VS Code** for writing and running code
- **Git** for cloning and managing the repository

This is optional for now. We will use Colab during the workshop.
